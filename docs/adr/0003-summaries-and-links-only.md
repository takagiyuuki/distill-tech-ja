# 自前生成の要約と原典リンクのみを扱い、原文は一切保持・配信しない

記事本文・コメント原文を DB に保存せず、配信にも含めない。扱うのは自前生成の日本語要約（原表現をなぞらない変形的要約）と、原典URL・HN議論スレッドURL へのリンクのみ。これは英語圏メディアの内容を再配信せずに公開する安全点であり、catnose 氏の先行プロダクトとの差別化（複数ソース＋議論要約）と両立させるための核心制約。

## Consequences

- スキーマは本文・コメント原文のカラムを持たない。抽出・取得した原文は要約への一時入力に留め、要約後に破棄する。
- 配信の性能最適化でも本文をキャッシュしない（キャッシュ対象は生成済み要約のみ）。
- 全記事エントリに原典URL＋HN議論スレッドURLを付与し、トラフィックを原典へ還元する。
- 要約プロンプトは「原表現をなぞらない」ことを明示的に指示する。
- robots.txt / 各ソースの利用規約を取得時に尊重する（特に Phase 7 の RSS・将来の本文抽出）。
